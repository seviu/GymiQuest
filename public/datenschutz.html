PRIVACY IN THE PRODUCT · UPDATED 17 JULY 2026

Your learning stays on your device.

The current version of GymiQuest deliberately has no accounts. Learning progress is stored in the browser so lessons, challenging reviews, and assessments work without a public profile or learning account.

No learning accountNo full name, login, or public profile is required.
No trackingNo advertising, analytics SDKs, or marketing of learning data.
Local controlDeletion and encrypted backups remain under the user’s control.

What is stored locally

  • nickname, exam date, and chosen study rhythm;
  • curriculum package and version, progress, XP evidence, mastery, review dates, and assessments;
  • question results, help usage, active learning time, and a paused session;
  • optional feedback about clarity, mock-exam results, and the history and self-comparisons of private archive training;
  • the selected app language as a small device setting in local browser storage;
  • for the parent area, only a salted verifier for the PIN—never the PIN itself—and the selected language of the shared coaching guide;
  • in the protected release log, only locally selected checks and their timestamps, kept separate from learning progress.

Learning progress is held in the local browser database (IndexedDB) of the device and browser profile in use. The app language is kept separately in Local Storage so onboarding and restoration can already appear in the selected language.

The protected companion view also summarises existing sessions into a local three-week overview. It stores no new answers, free text, or observation fields and sends no data.

What the app does not transmit

The current app does not send learning progress, answers, XP, mastery, review planning, timing, or the parent PIN verifier to a GymiQuest server. There is no background synchronisation, leaderboard, advertising, or product analytics. When the public website is loaded normally, the hosting provider still receives the usual technical request data, such as IP address, time, requested file, and browser information. That request data does not contain the local learning history from IndexedDB.

Private official exam PDFs

Personally imported question and solution PDFs for 2015–2025 are identified locally by checksum and stored only on this device. They are neither part of the public app package nor included in a GymiQuest backup, and the app does not upload them. After changing device or browser, they must be selected again from the user’s own collection.

Encrypted backup

A backup file is encrypted in the browser and then downloaded directly. The selected password is neither stored nor transmitted. Anyone holding both the file and password can read the learning data, so they should be kept separately. Active archive training and its bounded self-comparisons are included in learning progress; the private exam PDFs, parent PIN and coaching-guide language, and local release log are not included. The release log can be exported separately as a readable Markdown file.

Deletion and changing devices

“Reset local progress” removes learning progress, paused sessions, mock exams, archive training, imported PDFs, and parent access from GymiQuest on this device. The separate local release log and app language remain; the log can be cleared separately with “Reset local release checks,” and the language can be changed from the profile at any time. Alternatively, all site data can be deleted in the browser. Previously downloaded backup files are independent and must be deleted separately when needed.

If GymiQuest is expanded later

Public profiles, leagues, and cross-device accounts are not part of this version. If those features are introduced, data flows, consent, safeguards for children, and deletion paths must be explained and reviewed again before activation.

Technical product information

This page describes the behaviour currently implemented. Before a general public release, the responsible entity, a contact route, and the legal information required in the selected countries will also be added and professionally reviewed.

PRIVACIDAD EN EL PRODUCTO · ACTUALIZADO EL 17 DE JULIO DE 2026

Tu aprendizaje se queda en tu dispositivo.

La versión actual de GymiQuest no tiene cuentas de forma deliberada. El progreso de aprendizaje se guarda en el navegador para que las lecciones, los repasos exigentes y las evaluaciones funcionen sin un perfil público ni una cuenta de aprendizaje.

Sin cuenta de aprendizajeNo se necesita nombre completo, inicio de sesión ni perfil público.
Sin seguimientoSin publicidad, SDK de analítica ni comercialización de datos de aprendizaje.
Control localLa eliminación y las copias cifradas siguen bajo el control del usuario.

Qué se guarda localmente

  • apodo, fecha del examen y ritmo de estudio elegido;
  • paquete y versión del currículo, progreso, evidencias de XP, dominio, fechas de repaso y evaluaciones;
  • resultados de preguntas, uso de ayudas, tiempo activo de aprendizaje y una sesión pausada;
  • valoraciones opcionales sobre claridad, resultados de simulacros y el historial y las comparaciones personales del entrenamiento con archivos privados;
  • el idioma elegido para la aplicación como pequeño ajuste del dispositivo en el almacenamiento local del navegador;
  • para el área familiar, solo un verificador con sal del PIN, nunca el propio PIN, y el idioma elegido para la guía de acompañamiento compartida;
  • en el registro de publicación protegido, solo las comprobaciones elegidas localmente y sus marcas de tiempo, separadas del progreso de aprendizaje.

El progreso de aprendizaje se conserva en la base de datos local del navegador (IndexedDB) del dispositivo y perfil de navegador utilizados. El idioma de la aplicación se guarda por separado en Local Storage para que la bienvenida y la restauración ya puedan mostrarse en el idioma elegido.

La vista de acompañamiento protegida también resume las sesiones existentes en una vista local de tres semanas. No guarda respuestas nuevas, texto libre ni campos de observación y no envía datos.

Qué no transmite la aplicación

La aplicación actual no envía a un servidor de GymiQuest el progreso, las respuestas, los XP, el dominio, la planificación de repasos, los tiempos ni el verificador del PIN familiar. No hay sincronización en segundo plano, clasificación, publicidad ni analítica de producto. Cuando se carga normalmente el sitio público, el proveedor de alojamiento recibe los datos técnicos habituales de la solicitud, como dirección IP, hora, archivo solicitado e información del navegador. Esos datos no contienen el historial local de aprendizaje de IndexedDB.

PDF privados de exámenes oficiales

Los PDF de preguntas y soluciones de 2015–2025 importados personalmente se identifican localmente mediante una suma de comprobación y solo se guardan en este dispositivo. No forman parte del paquete público ni de una copia de seguridad de GymiQuest y la aplicación no los sube. Tras cambiar de dispositivo o navegador, deben volver a elegirse de la colección del usuario.

Copia de seguridad cifrada

El archivo de copia se cifra en el navegador y se descarga directamente. La contraseña elegida no se guarda ni se transmite. Quien tenga tanto el archivo como la contraseña puede leer los datos de aprendizaje, por lo que deben guardarse por separado. El entrenamiento de archivo activo y sus comparaciones limitadas forman parte del progreso; los PDF privados, el PIN familiar y el idioma de la guía, y el registro local de publicación no se incluyen. El registro se puede exportar por separado como archivo Markdown legible.

Eliminación y cambio de dispositivo

«Restablecer progreso local» elimina de GymiQuest en este dispositivo el progreso, las sesiones pausadas, los simulacros, el entrenamiento de archivo, los PDF importados y el acceso familiar. El registro local de publicación y el idioma de la aplicación se conservan; el registro se puede borrar por separado con «Restablecer marcas locales de publicación» y el idioma se puede cambiar en cualquier momento desde el perfil. Como alternativa se pueden borrar todos los datos del sitio en el navegador. Las copias descargadas anteriormente son independientes y deben eliminarse por separado cuando sea necesario.

Si GymiQuest se amplía más adelante

Los perfiles públicos, las ligas y las cuentas entre dispositivos no forman parte de esta versión. Si se incorporan, habrá que explicar y revisar de nuevo los flujos de datos, el consentimiento, la protección de menores y las vías de eliminación antes de activarlos.

Información técnica del producto

Esta página describe el comportamiento implementado actualmente. Antes de una publicación general también se añadirán y revisarán profesionalmente la entidad responsable, un canal de contacto y la información jurídica exigida en los países elegidos.

PRIVACY NEL PRODOTTO · AGGIORNATO IL 17 LUGLIO 2026

Il tuo apprendimento resta sul tuo dispositivo.

La versione attuale di GymiQuest non prevede volutamente alcun account. I progressi vengono salvati nel browser, così lezioni, ripassi impegnativi e verifiche funzionano senza un profilo pubblico o un account di apprendimento.

Nessun account di studioNon servono nome completo, accesso o profilo pubblico.
Nessun tracciamentoNessuna pubblicità, SDK di analisi o commercializzazione dei dati di apprendimento.
Controllo localeEliminazione e backup cifrati restano sotto il controllo dell'utente.

Che cosa viene salvato localmente

  • soprannome, data dell'esame e ritmo di studio scelto;
  • pacchetto didattico e versione, progressi, prove XP, padronanza, date dei ripassi e verifiche;
  • risultati delle domande, uso degli aiuti, tempo di studio attivo e una sessione in pausa;
  • riscontro facoltativo sulla chiarezza, risultati delle simulazioni, cronologia e autoconfronti degli allenamenti d'archivio privati;
  • la lingua dell'app selezionata, come piccola impostazione del dispositivo nella memoria locale del browser;
  • per l'area genitore, soltanto un verificatore con salt del PIN, mai il PIN stesso, e la lingua scelta per la guida condivisa;
  • nel registro di rilascio protetto, soltanto i controlli selezionati localmente e le relative date, separati dai progressi di apprendimento.

I progressi sono conservati nella banca dati locale del browser (IndexedDB) del dispositivo e del profilo browser in uso. La lingua dell'app viene salvata separatamente in Local Storage, così onboarding e ripristino possono già apparire nella lingua scelta.

L'area accompagnatore protetta riassume inoltre le sessioni esistenti in una panoramica locale di tre settimane. Non salva nuove risposte, testi liberi o campi di osservazione e non invia dati.

Che cosa l'app non trasmette

La versione attuale non invia a un server GymiQuest progressi, risposte, XP, padronanza, pianificazione dei ripassi, tempi o verificatore del PIN genitore. Non esistono sincronizzazione in background, classifiche, pubblicità o analisi del prodotto. Quando il sito pubblico viene caricato normalmente, il fornitore di hosting riceve comunque i consueti dati tecnici della richiesta, come indirizzo IP, ora, file richiesto e informazioni sul browser. Questi dati non contengono la cronologia locale di apprendimento presente in IndexedDB.

PDF privati degli esami ufficiali

I PDF delle domande e delle soluzioni 2015–2025 importati personalmente vengono identificati localmente tramite checksum e salvati soltanto su questo dispositivo. Non fanno parte del pacchetto pubblico dell'app né di un backup GymiQuest e l'app non li carica. Dopo un cambio di dispositivo o browser devono essere selezionati di nuovo dalla propria raccolta.

Backup cifrato

Il file di backup viene cifrato nel browser e poi scaricato direttamente. La password scelta non viene né salvata né trasmessa. Chi possiede sia il file sia la password può leggere i dati di apprendimento, perciò vanno conservati separatamente. Gli allenamenti d'archivio attivi e i relativi autoconfronti limitati sono inclusi nei progressi; i PDF privati degli esami, il PIN genitore e la lingua della guida, e il registro locale di rilascio non sono inclusi. Il registro di rilascio può essere esportato separatamente come file Markdown leggibile.

Eliminazione e cambio di dispositivo

«Azzera progressi locali» elimina da GymiQuest su questo dispositivo progressi, sessioni in pausa, simulazioni, allenamenti d'archivio, PDF importati e accesso genitore. Il registro locale di rilascio separato e la lingua dell'app rimangono; il registro può essere eliminato separatamente con «Azzera spunte locali di rilascio» e la lingua può essere cambiata in qualsiasi momento dal profilo. In alternativa, tutti i dati del sito possono essere eliminati nel browser. I file di backup già scaricati sono indipendenti e, se necessario, devono essere eliminati separatamente.

Se GymiQuest verrà ampliato

Profili pubblici, leghe e account tra dispositivi non fanno parte di questa versione. Se tali funzioni verranno introdotte, flussi di dati, consenso, tutele per i minori e percorsi di eliminazione dovranno essere spiegati e verificati nuovamente prima dell'attivazione.

Informazioni tecniche sul prodotto

Questa pagina descrive il comportamento attualmente implementato. Prima di un rilascio pubblico generale verranno inoltre aggiunti e verificati professionalmente il soggetto responsabile, un canale di contatto e le informazioni legali richieste nei Paesi selezionati.

DATENSCHUTZ IM PRODUKT · STAND 17. JULI 2026

Dein Lernen bleibt auf deinem Gerät.

GymiQuest ist in der aktuellen Version bewusst kontolos. Der Lernstand wird im Browser gespeichert, damit Lektionen, anspruchsvolle Reviews und Standortbestimmungen auch ohne öffentliches Profil oder Lernkonto funktionieren.

Kein LernkontoKein vollständiger Name, Login oder öffentliches Profil nötig.
Kein TrackingKeine Werbung, Analyse-SDKs oder Vermarktung von Lerndaten.
Lokale KontrolleLöschen und verschlüsselte Sicherung bleiben beim Nutzer.

Was lokal gespeichert wird

  • Spitzname, Prüfungstermin und gewählter Lernrhythmus;
  • Lehrplanpaket samt Version, Lernstand, XP-Belege, Mastery, Review-Termine und Standortbestimmungen;
  • Aufgabenresultate, Hilfe-Nutzung, aktive Lernzeit und eine pausierte Runde;
  • freiwillige Rückmeldung zur Verständlichkeit, Ergebnisse von Probeprüfungen sowie Verlauf und Selbstvergleich privater Archivtrainings;
  • die gewählte App-Sprache als kleine Geräteeinstellung im lokalen Browser-Speicher;
  • für den Elternbereich nur ein gesalzener Prüfnachweis der PIN, nie die PIN selbst, sowie die gewählte Sprache des gemeinsamen Begleitfadens;
  • im geschützten Freigabeprotokoll nur lokal gesetzte Prüfhaken und deren Zeitstempel, getrennt vom Lernstand.

Der Lernstand liegt in der lokalen Browser-Datenbank (IndexedDB) des verwendeten Geräts und Browserprofils. Die App-Sprache liegt getrennt davon in Local Storage, damit bereits Onboarding und Wiederherstellung in der gewählten Sprache erscheinen können.

Die geschützte Begleitansicht verdichtet vorhandene Lernrunden zusätzlich zu einem lokalen Drei-Wochen-Überblick. Dafür werden keine neuen Antworten, Freitexte oder Beobachtungsfelder gespeichert und keine Daten übertragen.

Was die App nicht überträgt

Die aktuelle App sendet Lernstand, Antworten, XP, Mastery, Review-Plan, Zeitmessung oder Eltern-PIN-Nachweis nicht an einen GymiQuest-Server. Es gibt keine Hintergrund-Synchronisation, Bestenliste, Werbung oder Produktanalyse. Beim normalen Laden der öffentlichen Website fallen beim Hosting-Anbieter jedoch die üblichen technischen Abrufdaten an, etwa IP-Adresse, Zeitpunkt, angeforderte Datei und Browserinformationen. Diese Abrufdaten enthalten nicht die lokale Lernhistorie aus IndexedDB.

Private offizielle Prüfungs-PDFs

Selbst importierte Aufgaben- und Lösungs-PDFs der Jahre 2015–2025 werden anhand ihrer Prüfsumme lokal erkannt und nur auf diesem Gerät gespeichert. Sie gehören weder zum öffentlichen App-Paket noch zur GymiQuest-Sicherung und werden von der App nicht hochgeladen. Nach einem Geräte- oder Browserwechsel müssen sie erneut aus der eigenen Sammlung gewählt werden.

Verschlüsselte Sicherung

Eine Sicherungsdatei wird im Browser verschlüsselt und anschliessend direkt heruntergeladen. Das gewählte Passwort wird weder gespeichert noch übertragen. Wer die Datei und das Passwort besitzt, kann den enthaltenen Lernstand lesen; beides sollte deshalb getrennt aufbewahrt werden. Laufende Archivtrainings und ihre begrenzten Selbstvergleiche gehören zum Lernstand; die privaten Prüfungs-PDFs selbst, Eltern-PIN samt Begleitfadensprache und das lokale Freigabeprotokoll gehören nicht zu dieser Lernstandsicherung. Das Freigabeprotokoll kann separat als lesbare Markdown-Datei exportiert werden.

Löschen und Gerätewechsel

„Lokalen Fortschritt zurücksetzen“ entfernt Lernstand, pausierte Runden, Probeprüfungen, Archivtrainings, importierte PDFs und den Elternzugang aus GymiQuest auf diesem Gerät. Das davon getrennte lokale Freigabeprotokoll und die App-Sprache bleiben erhalten; das Protokoll kann über „Lokale Freigabehaken zurücksetzen“ separat geleert und die Sprache jederzeit im Profil geändert werden. Alternativ können alle Website-Daten im Browser gelöscht werden. Bereits heruntergeladene Sicherungsdateien sind davon unabhängig und müssen bei Bedarf separat gelöscht werden.

Wenn GymiQuest später erweitert wird

Öffentliche Profile, Ligen und geräteübergreifende Konten sind nicht Teil dieser Version. Falls solche Funktionen hinzukommen, müssen Datenfluss, Einwilligungen, Schutz für Kinder und Löschwege vor der Aktivierung neu erklärt und geprüft werden.
